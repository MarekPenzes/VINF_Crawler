===== 1. Opis projektu =====

  * **Cieľ:** vyhľadávanie futbalových hráčov podľa textu (bio, kluby, súťaže) a podľa faktov (vek, výška, noha, zápasy a góly za klub a reprezentáciu).
  * **Postup:**
    * crawler stiahne profily hráčov z worldfootball.com,
    * regex extraktor z HTML vytiahne údaje do TSV,
    * vlastný indexer postaví invertovaný index (TF),
    * vyhľadávanie z príkazového riadku zoradí hráčov podľa TF-IDF (kosínusová podobnosť), voliteľne s filtrami.
  * **Pravidlá:** čistý Python, bez databázy, dáta v TSV, vlastný index.
  * **Spustenie:** všetko cez spoločný vstup ''main.py''.

<code>
py main.py crawl [--target N] [--retry]
py main.py extract
py main.py index
py main.py search "young striker ajax academy" age<23 --idf prob
py main.py compare
py main.py stats --html
py main.py test
py main.py all      (extract + index + test)
</code>

===== 2. Zdroj dát a extrahované dáta =====

  * **worldfootball.com**, profily hráčov ''%%/people/{slug}/{id}%%''
    (napr. [[https://worldfootball.com/people/b-saka/640]])
  * **Prečo táto stránka:**
    * kompletná tabuľka štatistík po sezónach (zápasy, góly, asistencie, karty, rating),
    * text bio,
    * statické HTML,
    * veľa odkazov na ďalších hráčov a tímy.
  * **Spojenie s Wikipédiou:** cez meno a dátum narodenia (oboje je na stránke hráča).
  * **Výstup extraktora:**
    * ''data/players.tsv'': 1 riadok = 1 hráč, 17 stĺpcov,
    * ''data/career.tsv'': 1 riadok = sezóna, tím a súťaž, 16 stĺpcov.

  * **Prečo nie Scrapy alebo Selenium:**
    * stránka je statické HTML, takže JavaScript ani prehliadač netreba,
    * pri jednom requeste naraz s pauzou by bol framework zbytočne zložitý.

===== 5. Architektúra crawlera =====

{{:user:marek.penzes:crawl_architecture.png |Diagram architektúry crawlera}}

Inšpirácia: [[https://www.hellointerview.com/learn/system-design/problem-breakdowns/web-crawler]], zmenšené na jeden proces a jednu doménu.

  * **Seedy:** Saka, Arsenal a 5 top líg. Sú to iba štartovacie body, ďalej sa crawler šíri cez odkazy (hráč, spoluhráči, klub, liga, ďalšie tímy).
  * **Frontier:** 3 fronty (hráči, tímy, súťaže).
    * Bežne sa berie hráč, každá 25. stránka je tím a každá 200. súťaž. Fronta hráčov sa nikdy nevyprázdni, inak by sa crawler k tímom nedostal.
    * Výber z fronty je náhodný, nie FIFO. Pri FIFO by sa od Arsenalu išlo iba po Anglicku.
  * **Fetcher:** 1 request naraz, 1 pokus na URL.
  * **Parser:** regexom vytiahne odkazy, nové URL idú do front, každá URL sa navštívi iba raz.
  * **Filter:** ukladá sa iba profil, ktorý má bio aj tabuľku štatistík. Tréneri a personál sa neukladajú, ale ich odkazy sa berú.
  * **Uloženie:** ''%%data/html/{id}_{slug}.html%%'' hneď po stiahnutí.
  * **Pokračovanie po prerušení:** každých 10 stránok sa uloží ''state.json'' (fronty, navštívené URL).
  * **Retry:** chybné URL (403, 429, 5xx, timeout, Cloudflare challenge) ostanú v logu a po vyprázdnení front sa raz zopakujú. Ručne: ''%%py main.py crawl --retry%%''.
  * **robots.txt:** ''%%User-agent: * Allow: /%%'', zakázané ''%%/api/, /cms, /healthz, /ops%%'' crawler preskakuje.

===== 6. Metadáta =====

Každý request sa zapíše do ''data/crawl_log.tsv''. Z neho sa počítajú štatistiky a podľa neho sa robí retry.

^ time ^ status ^ kind ^ bytes ^ seconds ^ url ^
| 2026-10-11 19:39:35 | 200 | player | 637882 | 2.73 | /people/b-saka/640 |
| 2026-10-11 19:39:38 | 200 | player | 560569 | 1.65 | /people/b-white-637/637 |
| 2026-10-26 15:15:40 | 200 | player | 554108 | 1.23 | /people/t-nakashima/55486 |

  * **status:** HTTP kód, ''None'' = timeout alebo chyba siete, ''CF'' = challenge stránka Cloudflare so statusom 200.
  * **kind:** typ stránky (''player'', ''team'', ''comp'').
  * **bytes, seconds:** veľkosť odpovede a čas requestu.
  * **state.json:** ''done'' (spracované URL), ''seen'' (URL, ktoré už boli vo fronte), ''queues'' (fronty).

===== 7. Hlavičky, timeouty, sleepy =====

^ Nastavenie ^ Hodnota ^ Dôvod ^
| Hlavičky | ako Chrome (''curl_cffi'', ''impersonate="chrome"'') | Web je za Cloudflare. Pôvodne crawler bežal cez ''urllib.request'' s hlavičkami prehliadača (User-Agent Chrome, Accept, Accept-Language). Po približne 2000 hráčoch Cloudflare vracal každému requestu 403 "Just a moment". Blokoval klienta podľa TLS odtlačku, nie IP, lebo rovnaký request cez ''curl_cffi'' prešiel so statusom 200. Pôvodný fetch som preto nahradil. ''Session'' drží spojenie a cookies. |
| Timeout | 20 s | Stránka má 450-650 kB, priemerná odpoveď 1.20 s. 20 s stačí aj pri pomalej odpovedi a zaseknutý request nezdrží crawl. |
| Sleep | náhodne 2-3 s | Šetrnosť k serveru, ochrana pred banom, bez pravidelného rytmu. Pôvodne 1-2 s, zvýšené po bloku od Cloudflare. |
| Pauza po bloku | 10 / 30 / 60 / 120 s | Podľa počtu blokov za sebou. Blok býva na celú IP, bez pauzy by padli aj ďalšie stránky. |
| Paralelizmus | 1 request naraz | Rovnaký dôvod ako pri sleepe. |

===== 8. Extrakcia URL z HTML =====

Súbor ''crawler.py''. Odkazy sa berú zo všetkých stiahnutých stránok, do front idú iba profily hráčov, tímy a súťaže.

<code python>
RE_PLAYER = re.compile(r"^/people/[^/]+/\d+$")
RE_TEAM = re.compile(r"^/[a-z-]+(?:/[a-z-]+)?/teams/[^/]+/\d+$")
RE_COMP = re.compile(r"^/[a-z-]+/[a-z-]+/competitions/[^/]+$")
RE_HREF = re.compile(r'href="(/[^"#?]*)"')
FORBIDDEN = ("/api/", "/cms", "/healthz", "/ops")


def kind(path):
    if RE_PLAYER.match(path):
        return "player"
    if RE_TEAM.match(path):
        return "team"
    if RE_COMP.match(path):
        return "comp"
    return None


class Crawler:
    def add(self, path):
        path = path.rstrip("/")
        if path in self.seen or path.startswith(FORBIDDEN):
            return
        k = kind(path)
        if k:
            self.seen.add(path)
            self.queues[k].append(path)

    # v hlavnej slucke po stiahnuti stranky (status 200):
    #     for href in RE_HREF.findall(html):
    #         self.add(href)
</code>

===== 9. Extrakcia entít z HTML =====

Súbor ''extractor.py''.

  * **Základné údaje:** z JSON-LD bloku ''Person'' v hlavičke stránky.
  * **Výška a noha:** z hlavičky profilu (v JSON-LD nie sú).

<code python>

RE_LD_NATION = re.compile(r'"nationality":' + JSON_STR)
RE_LD_CLUB = re.compile(r'"memberOf":\{[^}]*"name":' + JSON_STR)
RE_LD_POSITION = re.compile(r'"jobTitle":' + JSON_STR)

RE_HERO_META = re.compile(r'class="page-hero__meta">(.*?)</div>', re.S)
RE_HEIGHT = re.compile(r">(\d{3}) cm<")

def extract_person(page):

    ld = find(RE_PERSON, page)
    meta = find(RE_HERO_META, page)

===== 10. Indexer a index (TF) =====

Súbory ''indexer.py'' a ''tokenizer.py''.

  * **Dokument = 1 hráč:** ''name, position, club, nationality, national_team, foot, bio'' a názvy tímov a súťaží z ''career.tsv''. Každý názov sa berie raz, aby hráč s 15 sezónami v jednom klube nemal 15-krát vyššiu TF.
  * **Tokenizer:**
    * malé písmená, bez diakritiky (Müller na muller, Brøndby na brondby),
    * tokeny ''%%[a-z0-9]+%%'' s dĺžkou aspoň 2 znaky,
    * vlastný zoznam anglických stop slov,
    * dopyt prechádza rovnakým tokenizerom.
  * **index.tsv:** ''term'', ''df'' a postings ''doc_id:tf''.
  * **docs.tsv:** ''doc_id, name, length'' (počet termov dokumentu).
  * **Ako často sa vytvára:** celý naraz (batch) po každej extrakcii, teda po novom crawle (''%%py main.py all%%''). Nie je inkrementálny. Vyhľadávanie ho pri štarte načíta raz a predpočíta idf a normy dokumentov pre každú metódu.
  * **Skóre:** kosínusová podobnosť TF-IDF vektorov, váha výskytu ''1 + log(tf)''. Filtre pred výpočtom obmedzia množinu hráčov.

<code>
term     df   postings

saves    1    46:1
</code>

===== 11. Metódy výpočtu idf =====

N = počet dokumentov (3287), df = počet dokumentov s termom. Súbor ''search.py'', voľba ''%%--idf classic|smooth|prob%%''.

^ Metóda ^ Vzorec ^ Vlastnosť ^
| classic | log(N / df) | term vo všetkých dokumentoch má váhu 0 |
| smooth | log((N + 1) / (df + 1)) + 1 | žiadny term nemá váhu 0, časté termy stále trochu prispievajú |
| prob | max(0, log((N - df) / df)) | pravdepodobnostné idf (Manning, Introduction to IR), term aspoň v polovici dokumentov má váhu 0 |
